# W02 · CSS Box Model & Typography

Beginner · Dobozok, térközök és betűk · ~6 óra

## Landing oldal tipográfiával

Stílusozd meg az 1. heti landing oldaladat egy külön CSS fájllal. Legyen benne type scale, következetes spacing és olvasható szövegszélesség.

### Lépések

1. Hozz létre `styles.css`-t, és kösd be a HTML-be.
2. Állíts be `box-sizing: border-box`-ot mindenre.
3. Definiálj egy type scale-t CSS változókkal (pl. `--step-0`…`--step-4`).
4. Használj egy 4 vagy 8 pontos spacing rendszert.
5. Készíts képernyőképet, és tedd mellé, hogyan nézne ki ugyanez Figmában.
